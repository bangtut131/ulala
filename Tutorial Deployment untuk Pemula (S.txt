Tutorial Deployment untuk Pemula (Supabase + Netlify)
Dokumen ini panduan langkah demi langkah yang sangat rinci untuk mengonlinekan aplikasi rekrutmen Anda.

Prasyarat:

Akun GitHub (Daftar di github.com)
Akun Supabase (Daftar di supabase.com)
Akun Netlify (Daftar di netlify.com)
BAGIAN 1: Persiapan Database (Supabase)
Kita akan menyiapkan tempat penyimpanan data (database) dan file (CV).

Buat Project Baru

Login ke Dashboard Supabase.
Klik "New Project".
Name: hr-screening-app
Database Password: (Buat password kuat & Simpan di Notepad komputer Anda, Anda akan butuh ini nanti).
Region: Pilih Singapore (Paling dekat dengan Indonesia).
Klik "Create new project". Tunggu beberapa menit hingga status menjadi hijau ("Active").
Buat Tabel (Database)

Di menu kiri, klik ikon SQL Editor (gambar terminal/baris kode).
Klik tombol "+ New Query".
Copy dan Paste kode berikut ke kotak kosong:
-- Tabel Kandidat
create table candidates (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  full_name text not null,
  email text,
  phone text,
  position text,
  cv_url text,
  photo_url text,
  cv_text text,
  status text default 'New'
);
-- Tabel Hasil DISC
create table disc_results (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  candidate_id bigint references candidates(id) on delete cascade not null,
  d_score integer,
  i_score integer,
  s_score integer,
  c_score integer,
  profile text,
  answers jsonb
);
-- Tabel Analisa AI
create table analyses (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  candidate_id bigint references candidates(id) on delete cascade not null,
  match_score integer,
  verdict text,
  summary text,
  raw_response text,
  ocr_text text,
  content text
);
Klik tombol "RUN" (pojok kanan bawah editor). Tulisan "Success" akan muncul.
Buat Penyimpanan File (Storage)

Di menu kiri, klik ikon Storage (gambar ember).
Klik tombol "New Bucket".
Name of bucket: resumes
Public bucket: ⚠️ WAJIB DICENTANG/ON (Agar CV bisa diakses publik/AI).
Klik "Create bucket".
Ambil Kunci Rahasia (API Keys)

Klik ikon Settings (roda gigi) di menu kiri bawah.
Pilih menu "API".
Anda akan melihat bagian Project URL dan Project API keys.
Simpan (Copy-Paste) data ini ke Notepad:
Project URL (misal: https://xyz.supabase.co)
anon public key (string panjang dimulai dengan eyJ...)
BAGIAN 2: Upload Kode ke GitHub
Netlify membutuhkan kode Anda ada di GitHub agar bisa otomatis update.

Buka GitHub Desktop (atau pakai VS Code)

Jika belum punya, install GitHub Desktop.
Login dengan akun GitHub Anda.
Buat Repository Baru di GitHub Website

Buka github.com/new.
Repository name: hr-screening-app.
Pilih Private (agar data aman).
Klik Create repository.
Upload Kode dari VS Code

Di VS Code, klik ikon Source Control (cabang pohon/Y di menu kiri).
Klik tombol Publish to GitHub (jika ada) atau Initialize Repository.
Ikuti instruksi, pilih repository hr-screening-app yang baru dibuat.
Pastikan semua file ter-upload (Commit & Push).
BAGIAN 3: Deploy ke Netlify
Langkah terakhir untuk membuat website bisa diakses semua orang.

Buat Site Baru

Login ke Dashboard Netlify.
Klik "Add new site" -> "Import from Git".
Pilih GitHub. (Otorisasi jika diminta).
Cari dan pilih repository hr-screening-app Anda.
Konfigurasi Build

Netlify akan otomatis mendeteksi pengaturan dari file 
netlify.toml
 yang sudah saya buat.
Biarkan Build command, Publish directory, dll seperti default-nya.
Masukkan Environment Variables (PENTING!)

Klik tombol "Add environment variables" (atau New Variable).
Masukkan pasangan kunci dan nilai (Key & Value) berikut satu per satu:
Key (Nama Kunci)	Value (Isi Nilai)
SUPABASE_URL	Masukkan Project URL dari Supabase (Langkah 1.4)
SUPABASE_KEY	Masukkan anon public key dari Supabase (Langkah 1.4)
GEMINI_API_KEY	Masukkan API Key Google Gemini Anda
WAHA_BASE_URL	Masukkan URL WAHA Anda
WAHA_SESSION_ID	Masukkan Session ID WAHA Anda (default: Gamatriana)
Deploy

Klik tombol "Deploy site".
Tunggu proses "Building" selesai (biasanya 1-2 menit).
Jika sukses, Anda akan mendapatkan URL website (misal: https://hr-screening-app.netlify.app).
Selesai!

Buka URL tersebut. Website Anda sudah online! 🎉
Troubleshooting (Jika ada masalah)
Error saat register/login? Cek tab "Functions" di Netlify logs untuk melihat detail error.
Database error? Pastikan Anda sudah menjalankan script SQL di Supabase dengan benar.
Upload CV Gagal? Pastikan Bucket resumes di Supabase sudah diset ke Public.
